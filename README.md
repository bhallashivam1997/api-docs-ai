# api-docs-ai

A small Express 5 REST API for a demo. Users are kept in memory, so they disappear when the server restarts.

## Run it

Requires Node.js 20 or newer.

```bash
npm install
npm start            # listens on http://localhost:3000
PORT=8080 npm start  # or pick a port
```

## Endpoints

| Method | Path         | Success | Errors             | Description                  |
| ------ | ------------ | ------- | ------------------ | ---------------------------- |
| GET    | `/health`    | 200     | –                  | Returns `{ "status": "ok" }` |
| POST   | `/users`     | 201     | 400, 409           | Creates a user               |
| GET    | `/users/:id` | 200     | 404                | Fetches a user by id         |

`POST /users` accepts only these fields; any other field is rejected with 400:

- `name` (required): string, 1-100 characters after trimming.
- `email` (required): valid email address, trimmed, unique ignoring letter case (409 if taken).
- `role` (optional): `"admin"` or `"member"`, defaults to `"member"`.

## Example user

```json
{
  "id": "3f6c1a52-8d0e-4b7a-9a43-2f1d6b0e9c11",
  "name": "Ada Lovelace",
  "email": "ada@example.com",
  "role": "member",
  "createdAt": "2026-11-21T10:15:30.123Z"
}
```

`id` and `createdAt` are generated by the server.

## Errors

Every error response has the same shape:

```json
{
  "error": {
    "code": "invalid_input",
    "message": "email must be a valid email address"
  }
}
```

| Status | `code`           | When                                         |
| ------ | ---------------- | -------------------------------------------- |
| 400    | `invalid_input`  | Missing or invalid field, or an unknown field |
| 400    | `invalid_json`   | The body is not valid JSON                    |
| 404    | `not_found`      | Unknown user id or unknown route              |
| 409    | `email_taken`    | Email already used (ignoring letter case)     |
| 500    | `internal_error` | Unexpected server error                       |

## Example

```bash
curl -X POST http://localhost:3000/users \
  -H 'Content-Type: application/json' \
  -d '{"name": "Ada Lovelace", "email": "ada@example.com"}'
```
